# AutoWash – Car Washing & Detailing Website

A responsive car washing and detailing service website created as a class web-development project using HTML and CSS.

## Features

- Responsive navigation and hero section
- Animated hero background image slider
- About Us section
- Premium car washing services
- Service statistics
- Washing plans and pricing
- Washing point/location section
- Appointment/request form UI
- Team section
- Client testimonials
- Blog/news section
- Responsive footer and newsletter UI

## Technologies Used

- HTML5
- CSS3
- Font Awesome
- Responsive Web Design
- CSS animations

## How to Run

1. Download or clone this repository.
2. Open `index.html` in a web browser.

No backend or installation is required for the current class-project version.

## Notes

The contact, appointment, newsletter, and navigation controls are currently front-end UI elements. They do not submit data to a backend.
